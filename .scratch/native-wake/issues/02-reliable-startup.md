# 02: 统一启动与离线检查，使原生模式可重复启动

**What to build:** 维护者从命令行或容器使用同一套配置规则准备关键词并启动原生模式；环境或模型不足时在提供服务前明确失败。

**Blocked by:** 01: 收拢原生唤醒配置与完整分流路径

**Status:** ready-for-agent

- [ ] 项目 Python 满足要求时不受系统 Python 3.9 限制；命令行、检查与容器统一解析大小写和空白。
- [ ] 模型、关键词及模式配置检查统一，缺失时返回非零，不启动半就绪的服务；失败清理已创建的资源。
- [ ] 外部后端全部关闭时仍准备关键词并启动检测；不下载或预热全文 ASR，不连接外部 Agent/HA。
- [ ] 合并重复启动包装逻辑，更新运行说明；决定 HTTP API 默认关闭与是否允许手动开启，保持明确且一致。
- [ ] 补充真实启动编排配合假模型/传输的离线集成测试，覆盖就绪和失败路径；不把替身测试表述为真实模型成功。
