# 06: 完成新增入口与原厂功能并存验收

**What to build:** 用户可稳定使用新词进入原生小爱，了解音乐播放、服务中断和重启时的实际行为，并有可执行的停止与恢复方法。

**Blocked by:** 05: 安装匹配补丁与 Client，打通音箱到服务器链路

**Status:** ready-for-agent

- [ ] 新词→原生反馈→指令分两步验证天气、闹钟/计时器、音乐及已存在且可安全测试的米家功能；与改造前基线比较。
- [ ] 验证原厂词、多次唤醒、播放中唤醒和播报回声，记录次数、成功率、误唤醒与延时，不虚构指标。
- [ ] 验证 Bridge/Client 停止、连接中断和服务重启后的原厂功能与新增入口恢复表现。
- [ ] 清理验收中创建的闹钟、计时器等可撤销副作用；设备控制只在明确授权范围内执行。
- [ ] 运行手册包含真实版本、验收结果、已知限制、停止和回退步骤；失败项保持未完成，不将请求受理当作效果确认。
