# 05: Hermes 流式静默验收

**What to build:** 在完全隔离的 Mock Hermes 和静默 TTS 环境中证明流式对话的速度路径、最终回复正确性、回退和取消边界，形成可重复的验收记录。

**Blocked by:** 04: 对话流取消、工具边界与耗时埋点

**Status:** ready-for-human

- [x] 普通短回复能在完整响应前产生首句输出，且最终文字不丢不重
- [x] 长回复按顺序进入静默 TTS 接收器，工具进度不播报
- [x] 方言、语种、情绪和阶段偏好沿用现有 VoiceDirective 合同
- [x] 工具成功、工具失败、无进度话术和前置中性提示均符合 ADR-0008
- [x] 打断后旧流无迟到输出，新轮只发送一次请求
- [x] 非流式、畸形 SSE、断连和超时均安全回退或报告未知
- [ ] 运行原生唤醒、Hermes 现有测试和完整隔离测试套件；不连接生产 HA、音箱或容器
