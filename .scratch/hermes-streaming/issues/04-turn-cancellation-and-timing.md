# 04: 对话流取消、工具边界与耗时埋点

**What to build:** 用户打断时，Bridge 能停止当前流式回复和未播队列，丢弃旧事件并启动新轮；工具相关回复只在真实结果后播报，同时记录可诊断的阶段耗时。

**Blocked by:** 02: Hermes 流式连接与能力回退; 03: 流式分句与 TTS 队列

**Status:** ready-for-human

- [x] 取消只影响被取消轮次的流、TTS 和队列，不影响其他 session
- [x] 迟到文本、工具进度和终止事件不能进入新轮输出
- [x] 一轮用户输入只创建一个 Hermes 请求；已提交设备操作不回滚、不重发
- [x] 工具进度事件默认静默；Hermes 自然语言进度可按原文进入队列
- [x] 记录请求开始、首字节、首个完整句、TTS 开始、工具完成、终止和回退阶段
- [x] 计时记录不含凭据、原始音频、完整用户文本或 HA 参数
