# 06: 文件语音进入小爱豆包并验证现有 ASR

Status: ready-for-agent

**Parent:** [小爱豆包 spec](../spec.md)

**What to build:** 使用预先生成的音频文件，经现有 VAD/ASR 与对话入口进入小爱豆包，自动生成回复产物。优先验证普通话，记录英语、四川话识别表现，不播放音频。

**Blocked by:** 02 Vivi 自动播报与模型判断的阶段声音偏好；04 原生小爱与小爱豆包的混合唤醒路由。

依据：小爱豆包 spec、第二份 ADR。语音输出支持某种语言不等于输入已经能识别。复用当前 ASR 选择及连续对话入口，不新建平行识别框架，不将云端 ASR 凭据与 TTS 凭据混用。输入只来自测试文件和假 Client。

- [ ] 文件语音可经真实输入协调逻辑形成用户文字并得到回复产物，普通话输入闭环可验证。
- [ ] 按明确配置复用现有原生或外部 ASR 入口；本地模型缺失时准确报告，不把默认配置当作模型已部署。
- [ ] 真实本地识别与 Mock ASR 分开运行并记录；调用云端服务须使用专用凭据及隔离网络，无凭据时列为待测。
- [ ] 测试“豆包豆包”唤醒后讲话、多轮停顿、空识别、退出和监听超时，不把旧音频或 TTS 回声当作下一次请求。
- [ ] 未识别或不确定输入不触发猜测性设备操作，允许请求重说或继续等待。
- [ ] 英语、四川话以已有识别能力记录样本与实际结果，不为通过测试而假定其达到稳定准确率。
- [ ] 输入识别语言与输出语种/方言分别验证，不要求输入音频含方言就自动声称输出方言正确。
- [ ] 测试不用真实麦克风和音箱，不播放输入或合成音频；记录真人远场和听感验收尚未执行。
