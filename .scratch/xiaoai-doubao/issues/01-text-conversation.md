# 01: 小爱豆包文字对话与默认会话

Status: ready-for-agent
Execution: completed-mock (2026-10-28); real-hermes-pending

**Parent:** [小爱豆包 spec](../spec.md)

**What to build:** 在不连接真实音箱的环境中，输入文字即可由 `xiaoai-doubao` profile 的“小爱豆包”回答，默认会话可延续、恢复和显式重建；输出进入测试接收器。为后续语音与原生工具提供可用的用户请求入口。

**Blocked by:** None (can start immediately).

依据：项目“小爱豆包：Hermes 对话、原生指令与动态语音”spec 和第二份 ADR。本任务及后续验证均禁止真实音箱操作或发声，不重启生产服务。普通聊天自动输出，默认人格亲切、自然、简洁；一个默认 session，同一音箱暂共用。其他既有需求改动不属于本任务。

- [x] 通过现有 OpenAI 兼容通道完成一次文字输入到回复的路径，Mock 与真实服务验证分别报告。
- [x] 提供独立测试用的 profile/会话配置，不将 session 请求头视为 Agent profile 或工具权限已隔离的证据。
- [x] 新增和恢复默认 session 有明确状态归属，避免客户端历史与服务端历史重复叠加。
- [x] 再次进入默认 session 能延续上下文，进程重启后可恢复；开启新会话不继承旧聊天或旧声音偏好。
- [x] 测试入口默认只输出文字和测试产物，任何异常路径均不访问真实音箱；不加载生产工具或凭据。
- [x] Hermes 不可用、返回空值或超时时给出可观察错误，恢复后能继续新一轮，不重发历史请求。
- [x] 对话测试从请求入口验证结果、恢复与新会话行为；复用应用生命周期，不引入平行主循环。
- [x] 实际 Hermes profile 选择、权限和记忆协议未验证时明确列为待测，不将 Mock 结果计为真实服务通过。

## Comments

2026-10-28：新增静默文字命令入口，只连接进程自身创建的回环 Mock 服务，不接受真实地址或 API Key，不启动 MainApp、音箱或 TTS。独立配置中的 profile 和展示名仅标记本地测试身份，不代表已在真实 Hermes 创建 Agent。实际 profile 选择、工具隔离、记忆协议及模型效果留待独立环境验证。

复用 OpenAIManager 的发送和响应链路，可选 SQLite 会话历史以客户端上下文为唯一来源，默认保留最近 20 条消息。新会话清空上下文并原子更换远端会话标识，旧会话的迟到保存不可覆盖新会话。未启用持久化的现有后端继续使用内存历史。失败不加入成功历史，不自动重发；超时与关闭均取消未结束的网络任务。

4 项命令行行为测试覆盖正常回复、跨进程恢复、新会话和四类错误后的恢复。完整离线回归 88 项中 85 项通过、3 项真实服务测试跳过；另有 2 项 ASR 函数检查通过。原生扩展使用不可执行的替身，未连接设备或播放声音。新增源文件类型检查和 Python 编译检查通过；两路代码审查随后记录。
