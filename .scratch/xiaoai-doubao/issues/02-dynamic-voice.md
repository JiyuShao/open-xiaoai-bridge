# 02: Vivi 自动播报与模型判断的阶段声音偏好

Status: ready-for-agent

**Parent:** [小爱豆包 spec](../spec.md)

**What to build:** 小爱豆包每轮自动输出回复及合适的声音要求，在静默环境生成测试音频或记录合成请求。Hermes 根据 session 上下文动态决定情绪、语种、方言与阶段偏好，不要求每轮调用播放工具。

**Blocked by:** 01 小爱豆包文字对话与默认会话。

依据：小爱豆包 spec、第二份 ADR。默认声线固定为 Vivi 2.0（`zh_female_vv_uranus_bigtts`）；语气默认亲切自然，用户明确要求优先。只做当前 session 的阶段偏好，不建立长期声音画像。所有音频只保存或交给测试接收器，不能播放，降级路径亦如此。

- [ ] 明确并验证现有 Hermes 通道返回回复文字及本轮声音要求的方式，不预设任意 schema 强制输出已经被支持。
- [ ] 普通回复由共享 TTS 路由自动处理，无需 Agent 每轮调用播放 skill，不把声音元数据朗读出来。
- [ ] 流式、非流式和 Python/Rust 路径正确传递声音要求；移除相关路径将语种固定为中文的限制。
- [ ] 按官方 TTS 2.0 协议传递声音指令、语种和明确方言；Vivi 的情绪指令不误套其他音色的参数约束。
- [ ] 支持模型根据会话记忆延续或结束阶段偏好；单句覆盖不破坏阶段偏好，新会话不继承旧偏好，重新唤醒不硬重置。
- [ ] 参数类型、长度、不支持组合及异常模型输出得到校验或回退，不重发业务操作。
- [ ] TTS 凭据使用私有配置，适配实际鉴权形式；凭据缺失时 Mock 场景仍可运行，不回显秘密。
- [ ] 覆盖普通话、英语、四川话输出与情绪控制请求；真实合成在凭据可用时仅保存文件，格式/非空检查不冒充听感验收。
- [ ] Vivi 不可用时通过同一测试接收器验证原生音色降级与原因记录，不调用真实原生 TTS。
- [ ] 模型判断效果、真实合成、音色听感分别列明证据及待测项。
