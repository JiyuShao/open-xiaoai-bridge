# Hermes 流式响应与进度话术边界

Status: accepted

小爱豆包使用 Hermes 现有的 OpenAI-compatible 流式接口；Bridge 解析标准文本增量以及可选的 Hermes 工具进度事件，但不修改 Hermes 代码或镜像。Hermes 继续负责用户可见的自然语言、人格、语种、方言、情绪和最终结果，Bridge 负责事件转换、句子排队、取消、顺序和播放；工具事件本身不直接播报，Hermes 没有生成进度话术时 Bridge 默认等待最终结果，不自行编造语义提示。

普通聊天可以按句流式合成；涉及工具的请求必须以真实工具结果为最终依据，不能在工具完成前播报“已打开”或“已完成”。Bridge 只执行一条选定的设备路径，打断时取消未完成的回复并保留已提交操作记录。流式能力验证、分句、取消和工具状态测试先在静默环境完成；静默验收不得播放音箱、调用 Home Assistant 设备动作或重启生产服务。
